Privacy Policy

Hidden Wonders Uploader · Last updated November 2, 2026

Who we are

Hidden Wonders Uploader is the private publishing tool of the Hidden Wonders YouTube channel. It runs only on the channel owner's own computer and is used only with the Hidden Wonders channel. Contact: hiddenwonders5432@gmail.com.

What the tool accesses

When the channel owner signs in with Google, the tool asks for permission to use the YouTube Data API with these scopes:

  • youtube.upload, to upload the channel's videos and set their thumbnails.
  • youtube.force-ssl, to set video titles, descriptions and schedules, to post, pin and like comments on the channel's own videos, and to read comments on those videos so the owner can reply to viewers.

The tool does not access Gmail, contacts, Drive, payment details or any account other than the Hidden Wonders channel.

How the data is used and stored

  • The Google sign-in token is stored only in a file on the channel owner's computer. It is never sent anywhere except to Google.
  • Comments read from the channel's videos are used only to reply to viewers and to choose topics for future videos. A short log of replies is kept on the owner's computer.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • There is no server, database, analytics or tracking. This website sets no cookies.

Google API Services User Data Policy

Hidden Wonders Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The tool uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends the tool's access. Stored data is deleted on request; email the address above.

Changes

If this policy changes, the new version will be posted on this page with a new date.
